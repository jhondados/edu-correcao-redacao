# 🎓 Correção Automática de Redação

> Correção automática de redações no modelo ENEM com IA. Avalia as 5 competências, aponta erros, sugere melhorias e dá nota com feedback pedagógico detalhado em segundos.

**🌐 Demo ao vivo (web app interativo):** https://jhondados.github.io/edu-correcao-redacao/

## 📊 Resultados-chave (KPIs)
**0.89** Correlação · **5** Competências · **seg vs dias** Tempo · **escala** Redações

## 🧠 Tecnologias de IA
NLP · LLM · Deep Learning

## ✨ O que faz
- Avaliação das 5 competências ENEM
- Detecção de erros gramaticais
- Feedback pedagógico
- Nota fundamentada
- Correção em escala

## 🗄️ Fonte de dados real
[ENEM/INEP + redações corrigidas](https://www.gov.br/inep)

## ⚙️ Como funciona
1. **Coleta de dados reais** — integração com ENEM/INEP + redações corrigidas
2. **Processamento com IA** — NLP · LLM · Deep Learning
3. **Dashboard & insights** — KPIs, gráficos e recomendações acionáveis
4. **Ação automatizada** — alertas, predições e decisões em tempo real
